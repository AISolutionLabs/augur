# Security model

!!! info "Reporting a vulnerability"
    Report privately with GitHub's **Report a vulnerability** button under [Security → Advisories](https://github.com/AniAIApps/augur/security/advisories), not in a public issue. Include the version, configuration (API format, auth method, MCP setup) and steps to reproduce. We aim to acknowledge within 3 working days. The latest minor release receives fixes.
